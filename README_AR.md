# FitNova 100/100 — نسخة خفيفة

- تمت إزالة صور التمارين والأغذية الافتراضية الثقيلة بالكامل.
- بقيت أيقونات التطبيق فقط للواجهة وPWA.
- كل تمرين ووجبة موضحان كتابةً مع تفاصيل عملية.
- يمكن إضافة صورة شخصية للتمرين أو الوجبة من المعرض أو الكاميرا، وتخزينها على الجهاز فقط.
- صفحات HTML منفصلة: الرئيسية، التمارين، التغذية، المدرب، التطور، الإعدادات.
- ثيم داكن أخضر وثيم فاتح أزرق مع تبديل مباشر.
- Service Worker خفيف لا يحمل الصور مسبقاً.
- Cloudflare Worker + Static Assets + Workers AI Binding باسم `AI`.
- لا توجد مفاتيح OpenAI أو Environment Variables مطلوبة.

## Cloudflare
ارفع محتويات مجلد `FitNova_Pro` إلى جذر مستودع GitHub، واجعل Root Directory `/`، ثم تأكد من وجود Workers AI Binding باسم `AI`.
